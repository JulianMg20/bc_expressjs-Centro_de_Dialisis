## Dominio del bootcamp

Todos los proyectos de este repositorio se desarrollan sobre el dominio de un **Centro de Diálisis**, adaptando cada actividad semanal a este contexto (pacientes, tratamientos, turnos, costos de sesión, etc.).

## 📁 Estructura del repositorio

```
BC-EXPRESSJS-ERICK_GRANADOS/
├── week-01/
│   └── starter/          # Procesador de datos CLI - Centro de Diálisis
├── week-02/               # (próximas entregas)
└── ...
```

Cada carpeta `week-XX/` contiene su propio `README.md` con el detalle específico de esa entrega: objetivo, cómo correrlo, y qué requisitos cumple.
